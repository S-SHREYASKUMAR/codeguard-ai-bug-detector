    How the hybrid system works

    Code
    →
    Parser
    →
    Static rules
    ML classifier
    →
    Combiner
    →
    Report

    Engine A names CWE-style bugs with line numbers. Engine B, trained on CodeXGLUE Defect Detection (Devign), only scores defective vs clean and highlights risky tokens. The combiner merges both per function.

    Limitations

    • ML labels are function-level; the model cannot name a bug type.
    • Rules are conservative C/C++ heuristics, not a full compiler or sanitizer.
    • Accuracy around 60–65% is normal for this benchmark.

    Citation

    Zhou et al., Devign (NeurIPS 2019); CodeXGLUE defect detection benchmark (Microsoft).
